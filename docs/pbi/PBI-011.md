# PBI-011: インデクサ CLI (setup / index / reindex / search)

- 担当モデル: haiku
- 依存: PBI-008, PBI-009

## 目的
人と定期実行から使う CLI の入口を作る。`pnpm sm <command>` で core の関数を呼ぶ。この PBI では `setup` `index` `reindex` `search` の 4 つを実装し、`decay` `gc` `import` は後続 PBI が同じファイルに足す。

## 対象 (リポジトリルート = `C:\Users\owner\dev\shared-memory`)
- `packages/indexer/src/cli.ts` … `docs/design/interfaces.md` 11章のうち `setup` / `index` / `reindex [--keep-old]` / `search <query> [--scope s] [--limit n]`。共通オプション `--json`。未知のコマンドや引数なしは使い方を表示して終了コード 1。後続 PBI がコマンドを足しやすいよう、コマンド名 → 関数 の対応表 (オブジェクト) で振り分ける。引数解析は `node:util` の `parseArgs`。
- `packages/indexer/test/cli.int.test.ts` (新規)

## 触らない範囲
- `packages/core/` 配下すべて (呼ぶだけ。不具合を見つけたら直さずに報告する)
- `packages/mcp-server/`, `package.json`, `config.yaml`, `docs/`
- 本番のエイリアス `memories`・リポジトリの `memories/` と `state/` (テストでは使わない)

## 受け入れ条件
1. 検証コマンド1の TAP 出力が `# fail 0` で、`# pass` が 4 以上
2. 検証コマンド2が終了コード 0
3. 検証コマンド3が終了コード 1 で、使い方 (`setup` `index` `reindex` `search` を含む) を表示する
4. 結合テストが少なくとも次を確認している: (a) `setup` が終了コード 0 (b) メモリ 3 件を置いて `index --json` → 出力 JSON の `scanned` が 3 (c) `search <その1件の内容に関する語> --json` → 1 件目の id が期待どおり (d) `reindex --json` → 出力 JSON の `index` が `-r` を含む新しい名前 (e) 不正な front matter のファイルがあっても `index` は終了コード 0 で、その path を出力に含む

## 補足
- 仕様の正本は `docs/design/interfaces.md` 8・9・11章。
- 結合テストは本番に触れないよう、`os.tmpdir()` に一時ルートを作って子プロセスで CLI を起動する:
  - 一時ルートに `pnpm-workspace.yaml` (中身は `packages: []` でよい) と `config.yaml` を置く。`config.yaml` は本番のものを `yaml` で読み、`opensearch.alias` を `test-cli-<乱数>`、`index_base` を `test-cli-<乱数>-idx` (エイリアスとインデックスは同名にできない。起動時に修正)、`pipeline_name` を `test-cli-<乱数>-pipeline` に、`opensearch.template_file` / `pipeline_file` を本番リポジトリの絶対パスに、`memories_dir` などは一時ルート内の相対パスにして書き出す。
  - `child_process.spawnSync(process.execPath, [<リポジトリの packages/indexer/src/cli.ts の絶対パス>, ...args], { env: { ...process.env, SHARED_MEMORY_ROOT: <一時ルート> } })`。
  - 後片付けで `test-cli-` のインデックス・パイプラインと一時ルートを消す。
- core の関数は `@shared-memory/core` から import する。`Deps` は `new OpenSearchClient(cfg.opensearch.url)`, `new Embedder(cfg.embedding, cfg.cache_dir)`, `new StatsStore(cfg.state_db)` で組み立て、終了前に `stats.close()`。
- (起動時に追記) `--json` のときは標準出力に JSON だけを出す。メモリファイルは `serializeMemory` で書き、ULID は固定値でよい。
- 人向けの出力は日本語で簡潔に (例 `走査 12 件 / 埋め込み 3 (キャッシュ 9) / 投入 3 / 更新 0 / 削除 0`)。
