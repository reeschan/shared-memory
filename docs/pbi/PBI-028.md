# PBI-028: 結合テストの接続先を設定ファイル (config.local.yaml を含む) から読む

- 担当モデル: dsh deepseek-official/deepseek-flash high（sonnet / normal）
- 依存: なし (PBI-018〜027 は完了済み)

## 目的
結合テストのうち 3 本が OpenSearch・Ollama の接続先を既定 (127.0.0.1:9200 / 127.0.0.1:11434) に固定している、または config.yaml だけを読んでいる。そのため、config.local.yaml でトンネル (127.0.0.1:19200 / 127.0.0.1:11435) を指す PC では `pnpm test:int` が 14 件落ちる。ほかの結合テストと同じく `loadConfig()` (config.yaml に config.local.yaml を重ねたもの) の値を使うようにして、どの PC でも設定どおりの接続先でテストが動くようにする。

## 対象
- `packages/core/test/opensearch.int.test.ts`: `new OpenSearchClient("http://127.0.0.1:9200")` を `new OpenSearchClient(loadConfig().opensearch.url)` にする (`loadConfig` は `../src/config.ts` から import)
- `packages/core/test/embed.int.test.ts`: 手で組み立てている embedding の設定 (url 11434 固定) をやめ、`createEmbedder(loadConfig().embedding, dir)` にする。テスト名と期待値は「設定の dimension と同じ長さのベクトルを返す」に直す (`assert.equal(v.length, cfg.embedding.dimension)`)
- `packages/indexer/test/cli.int.test.ts`: `before` で一時ルートの config.yaml を作るとき、`opensearch.url` と `embedding.url` を `loadConfig()` の値で上書きする (ほかの項目は今までどおり config.yaml から)。`os = new OpenSearchClient(...)` も `loadConfig().opensearch.url` を使う。`loadConfig` は `@shared-memory/core` から import する (export されていなければ `../../core/src/config.ts` から)

## 触らない範囲
- packages/*/src/ のすべて (テストだけを直す)
- `packages/core/test/int-helpers.ts` と、ほかの結合テスト (既に loadConfig を使っている)
- config.yaml・config.local.yaml・config.local.example.yaml
- README.md、.gitignore、scripts/、lab/、docs/experiments/

## 受け入れ条件
1. 検証 1 が出力なし・exit 1 (3 本のテストに 9200・11434 の固定が残っていない)
2. 検証 2 (型チェック) が exit 0
3. 検証 3 (OpenSearch の結合テスト) が exit 0・`# fail 0`
4. 検証 4 (埋め込みの結合テスト) が exit 0・`# fail 0`
5. 検証 5 (CLI の結合テスト) が exit 0・`# fail 0`
6. 検証 6 (結合テスト全体) が exit 0・`# fail 0`
7. 検証 7 が出力なし・exit 0

## 検証コマンド
1. `git grep -nE "9200|11434" -- packages/core/test/opensearch.int.test.ts packages/core/test/embed.int.test.ts packages/indexer/test/cli.int.test.ts`
2. `pnpm typecheck`

6. `pnpm test:int`
7. `python docs/pbi/tools/unchanged.py check PBI-028`

## 補足
- お手本は `packages/core/test/int-helpers.ts` の `makeTestEnv` (`const base = loadConfig();` から接続先を取る)。
- cli.int.test.ts の CLI は、環境変数 `SHARED_MEMORY_ROOT` で一時ルートを指して起動するので、一時ルートの config.yaml に正しい url を書く必要がある。一時ルートには config.local.yaml を置かない (memories_dir などが上書きされるため)。
- 結合テストは実物の OpenSearch・Ollama に接続する。サンドボックスで接続できなければ、そのことを報告に書けばよい (検証 3〜6 はオーケストレーターが行う)。
- .ts を直接実行するには Node 26 が要る。
