# PBI-027: ローカルのリランカー (TEI) の compose プロファイルと、mcp-setup の Mac/Linux 手順

- 担当モデル: (prepare.py の表から)
- 依存: なし

## 目的
本文を外に出さずにリランクできるよう、TEI (Hugging Face Text Embeddings Inference) を docker-compose の任意のプロファイルとして足す。あわせて、mcp-setup の Skill に Windows 以外での登録手順を書く (今は register.ps1 だけ)。

## 対象
- `docker-compose.yml`: サービス `reranker` を足す
  - `profiles: ["rerank"]` (既定の `docker compose up` では起動しない)
  - image `ghcr.io/huggingface/text-embeddings-inference:cpu-1.8`
  - command `--model-id BAAI/bge-reranker-v2-m3`
  - ports `127.0.0.1:8081:80` (127.0.0.1 限定。既存のサービスと同じ方針)
  - volumes `./.cache/tei:/data` (モデルのキャッシュ)
  - 既存のサービス (opensearch) の定義は変えない
- `skills/mcp-setup/SKILL.md`: 「Windows 以外 (macOS / Linux)」の節を足す。register.ps1 を使わず、エージェントが次を順に行う
  1. `SHARED_MEMORY_ROOT` を確かめる (必須。無ければ聞く)
  2. 疎通確認 (`curl -s http://127.0.0.1:7820/mcp` 相当。既存の Windows の手順の確認内容に合わせる)
  3. エージェントごとの MCP 登録 (Claude Code: `claude mcp add --transport http shared-memory http://127.0.0.1:7820/mcp --scope user`。Codex・Kimi は既存の register.ps1 が書く設定ファイルの中身を読んで、同じ内容を書く手順にする)
  4. Skill の配置 (`ln -s "$SHARED_MEMORY_ROOT/skills/<名前>" ~/.claude/skills/<名前>` など。既存の register.ps1 が配置する先と同じ)
  5. 指示ファイルへの追記 (register.ps1 が追記するブロックと同じ文面。既にあれば追記しない)
  - pwsh は前提にしない

## 触らない範囲

- docker-compose.yml の既存のサービス
- README.md (PBI-026 が書く)、.gitignore、scripts/、lab/、docs/experiments/、packages/

## 受け入れ条件
1. 検証 1 の出力が `opensearch` だけ (プロファイルを指定しなければ reranker は入らない)
2. 検証 2 の出力に `opensearch` と `reranker` の両方がある
3. 検証 3 の出力が 1 以上 (ポートが 127.0.0.1 限定)
4. 検証 4 の出力が 3 以上 (SKILL.md に Windows 以外の手順がある)
5. 検証 5 が出力なし・exit 0

## 検証コマンド
1. `node -e "const y=require('module').createRequire(process.cwd()+'/packages/core/')('yaml');const d=y.parse(require('fs').readFileSync('docker-compose.yml','utf8'));console.log(Object.entries(d.services).filter(([k,v])=>!v.profiles).map(([k])=>k).join(','))"`
2. `node -e "const y=require('module').createRequire(process.cwd()+'/packages/core/')('yaml');const d=y.parse(require('fs').readFileSync('docker-compose.yml','utf8'));console.log(Object.keys(d.services).join(','))"`
3. `grep -c "127.0.0.1:8081:80" docker-compose.yml`
4. `grep -cE "SHARED_MEMORY_ROOT|ln -s|claude mcp add" skills/mcp-setup/SKILL.md`
5. `python docs/pbi/tools/unchanged.py check PBI-027`

## 補足
- 仕様は `docs/specs/pluggable-embedding-and-rerank.md` の「リランク」と「Mac / Linux の手順」。
- この PC では Docker が動いていないので、`docker compose config` での確認はしない。YAML として正しいことは検証 1・2 で見る (`yaml` パッケージはリポジトリの依存にある。見つからなければ `packages/core` から require する形に直してよい)。
- TEI の image のタグと、bge-reranker-v2-m3 が TEI で動くかは未実測。docker-compose.yml のサービスの上にコメントで「モデルとタグは実測して決める。Apple Silicon で動かない場合は llama.cpp の llama-server --reranking を使う」と書く。
- SKILL.md は日本語。既存の文体に合わせる。
