# PBI-004: core のチャンク分割とハッシュ

- 担当モデル: sonnet
- 依存: PBI-003

## 目的
メモリ本文を検索用のチャンクに分け、差分インデックスと埋め込みキャッシュのキーになるハッシュを計算する。

## 対象 (リポジトリルート = `C:\Users\owner\dev\shared-memory`)
- `packages/core/src/chunk.ts` … `docs/design/interfaces.md` 4章 (`Chunk`, `chunkMemory`, `sha256`, `contentHash`)
- `packages/core/test/chunk.test.ts` (新規)

## 触らない範囲
- `packages/core/src/index.ts` と、`chunk.ts` 以外の `packages/core/src/*.ts` (`frontmatter.ts` の `MemoryMeta` 型は `import type` で使うだけ)
- `package.json`, `config.yaml`, `docs/`

## 受け入れ条件
1. 検証コマンド1の TAP 出力が `# fail 0` で、`# pass` が 8 以上
2. 検証コマンド2が終了コード 0
3. テストが少なくとも次を確認している: (a) 見出しごとに分かれる (b) コードフェンス内の `#` 行で分かれない (c) 2000 字の 1 節が max_chars (800) 以下の本文片を持つ複数チャンクになる (d) 全チャンクの text が `"<title>\n\n"` で始まる (e) chunk_no が 0 からの連番 (f) 空本文で title だけのチャンク 1 個 (g) 同じ入力で `contentHash` が同じ、tags の順序違いでも同じ、title が違えば違う (h) `sha256("abc")` が `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`

## 検証コマンド
1. `node --test --test-reporter=tap packages/core/test/chunk.test.ts`
2. `pnpm typecheck`

## 補足
- 仕様の正本は `docs/design/interfaces.md` 0章と4章。ハッシュは `node:crypto` の `createHash("sha256")`。
- 文字数は JavaScript の `string.length` で数えてよい。max_chars の制限は本文片 (title 接頭辞を除いた部分) に対して適用する。
