# PBI-020: MCP の write と knowledge-import の Skill で出典を受け付ける

- 担当モデル: (prepare.py の表から)
- 依存: PBI-019

## 目的
PBI-019 で front matter に足した `source_path` / `source_sha256` を、エージェントが MCP の `write` と knowledge-import から渡せるようにする。

## 対象
- `packages/core/src/memory-store.ts`: `WriteInput` に `source_path?` / `source_sha256?` を足し、meta に写す (既存の `symbol_ref` と同じ扱い)
- `packages/mcp-server/src/app.ts`: `write` の inputSchema に `source_path: z.string().min(1).max(1000).optional()` と `source_sha256: z.string().regex(/^[0-9a-f]{64}$/).optional()` を足す。describe は英語で「Path of the source document this memory was extracted from」「SHA-256 (lowercase hex) of that source document」
- `packages/core/test/memory-store.test.ts`: 出典付きの WriteInput から作った front matter に 2 つの項目が入るテストを足す (既存のテストの書き方に合わせる。単体で書けなければ、meta を組み立てる部分のテストでよい)
- `skills/knowledge-import/SKILL.md`: 次を足す
  - JSONL の項目の表に `source_path` / `source_sha256` (任意) を足す
  - 規則: ファイルから取り込むときは、2 つの項目を必ず付ける。ハッシュの求め方を OS ごとに書く (Windows: `(Get-FileHash -Algorithm SHA256 <path>).Hash.ToLower()`、macOS: `shasum -a 256 <path>`、Linux: `sha256sum <path>`)。本文末尾の `出典: <パス>` も今までどおり残す。会話や貼り付けからの取り込みでは付けない
  - リポジトリの場所: Windows 以外では環境変数 `SHARED_MEMORY_ROOT` で指定することを必須とする (今の既定パスの記述の近くに書く)

## 触らない範囲
- frontmatter.ts・import.ts (PBI-019 で済み)
- app.ts の write 以外のツールと、Embedder を作る部分
- README.md、.gitignore、scripts/、lab/、docs/experiments/

## 受け入れ条件
1. 検証 1 が exit 0・`# fail 0`
2. 検証 2 (型チェック) が exit 0
3. 検証 3 の出力が 2 以上 (app.ts に 2 つの項目がある)
4. 検証 4 の出力が 3 以上 (SKILL.md に source_sha256 と SHARED_MEMORY_ROOT の記述がある)
5. 検証 5 が exit 0・`# fail 0`
6. 検証 6 が出力なし・exit 0

## 検証コマンド
1. `node --test --test-reporter=tap packages/core/test/memory-store.test.ts`
2. `pnpm typecheck`
3. `grep -cE "source_path|source_sha256" packages/mcp-server/src/app.ts`
4. `grep -cE "source_sha256|SHARED_MEMORY_ROOT" skills/knowledge-import/SKILL.md`
5. `pnpm test`
6. `python docs/pbi/tools/unchanged.py check PBI-020`
