## 受け入れ条件
1. 検証コマンド1が終了コード 0
2. 検証コマンド2が終了コード 0 (型エラーなし)
3. 検証コマンド3が `not implemented` を出力
4. 検証コマンド4が `ok` を出力 (core の 12 モジュールが workspace 越しに読み込める)

## 検証コマンド
1. `pnpm install`
2. `pnpm typecheck`
3. `pnpm sm`
4. `node --input-type=module -e "await import('@shared-memory/core'); console.log('ok')"` を `packages/indexer` ディレクトリで実行: `cd packages/indexer && node --input-type=module -e "await import('@shared-memory/core'); console.log('ok')"`

## 補足
- Node 26 は `.ts` を直接実行できる。workspace のシンボリックリンク越しでも実パスが `node_modules` 外なので型ストリップされる。
- `tsconfig.base.json` の必須オプションは `docs/design/interfaces.md` 0章を見る。
