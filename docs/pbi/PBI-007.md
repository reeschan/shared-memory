# PBI-007: core のアクセス統計ストア (node:sqlite)

- 担当モデル: sonnet
- 依存: PBI-003

## 目的
メモリごとのアクセス回数・最終アクセス日・tier を SQLite ファイル 1 つに持つ。MCP の `get` で更新し、インデクサが OpenSearch へ埋め戻す。

## 対象 (リポジトリルート = `C:\Users\owner\dev\shared-memory`)
- `packages/core/src/stats.ts` … `docs/design/interfaces.md` 7章 (`Stat`, `StatsStore`)。テーブル定義は `docs/design/design.md` 3.2章
- `packages/core/test/stats.test.ts` (新規)

## 触らない範囲
- `packages/core/src/index.ts` と、`stats.ts` 以外の `packages/core/src/*.ts` (`frontmatter.ts` の `Tier` 型は `import type` で使うだけ)
- `state/` (テストの DB は `os.tmpdir()` 配下の一時ディレクトリに作り、最後に消す)
- `package.json`, `config.yaml`, `docs/`

## 受け入れ条件
1. 検証コマンド1の TAP 出力が `# fail 0` で、`# pass` が 5 以上
2. 検証コマンド2が終了コード 0
3. テストが少なくとも次を確認している: (a) 存在しない親ディレクトリにも DB を作れる (b) `recordAccess` を 2 回で count=2・last が 2 回目の値・tier=hot (c) `setTiers` が count と last を保持したまま tier だけ変える、行が無い id は count=0 で作る (d) `all()` が全行を Map で返す (e) `close` 後に同じパスで開き直すと値が残っている

## 検証コマンド
1. `node --test --test-reporter=tap packages/core/test/stats.test.ts`
2. `pnpm typecheck`

## 補足
- 仕様の正本は `docs/design/interfaces.md` 0章と7章。
- `import { DatabaseSync } from "node:sqlite"`。プリペアドステートメントを使う。トランザクションは `db.exec("BEGIN")` / `COMMIT` / 失敗時 `ROLLBACK`。
- ジャーナルモードは既定 (DELETE) のままにする (WAL の付随ファイルを Git に出さないため)。
